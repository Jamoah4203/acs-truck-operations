- Reworked dashboard period controls so phone users never lose actions off-screen.
- Converted dashboard and table filters to responsive desktop dialogs and mobile bottom sheets.
- Reduced dashboard card count and combined delivery status counts for an even two-row summary.
- Reduced phone/tablet padding, record-card height and repetitive action text.
- Added dedicated narrow-phone and tablet behavior.
- Reworked Settings navigation and professional invoice/P&L presentation.

- Hardened Supabase-backed attachments so logos, receipts, invoices, proof of delivery, photos and maintenance documents persist centrally across devices.
- Added attachment metadata, classifications, secure role-aware access, signed open/download flows and upload orphan cleanup.
