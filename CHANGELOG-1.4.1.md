# v1.4.1

## Mobile-first refinement
- Reworked dashboard period controls so phone users never lose the Apply action off-screen.
- Converted dashboard filter to a phone bottom sheet and icon-first trigger.
- Reduced phone header, dashboard metric, register, report, settings and statement spacing.
- Tightened mobile record cards and converted repeated card actions to icon-only controls.
- Improved narrow-phone behaviour at 390px and below.
- Added dedicated tablet behaviour between 761px and 1100px.
- Made report controls, custom date ranges, details and forms responsive without horizontal overflow.
- Preserved desktop density while treating phone/tablet layouts as first-class interfaces.
